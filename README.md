# ratewire.io

Placeholder page for https://ratewire.io/ (static, GitHub Pages, no build step). Rebuilt Oct 11, 2026.

- `brand/`: RateWire logo system. `ratewire-seal-*` (badge with name), `ratewire-emblem-*` (badge only), `ratewire-logo-*` (horizontal lockup). SVG (text converted to outlines) plus PNG (seal and emblem 4096 px, lockup 5120 px wide). `-dark` is for dark backgrounds, `-light` for light backgrounds.
- `img/hero-3840.*`: hero photograph by Polina Kuzovkova on Unsplash (https://unsplash.com/photos/aerial-view-of-city-buildings-during-night-time-zd8v_Ig3ndg), downsampled from the 6000x4000 original (never upscaled). Unsplash License.
